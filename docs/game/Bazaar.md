## Overview

As players will come to learn from performing [Realm Quests](<Realm Quests.md>), there are a lot of [Unique Items](<Unique Items.md>) out there in the world. Unique items are used for:
- Upgrading base Knight stats
- Upgrading base Mount stats
- Upgrading base loadout items

Some items aren't even of this realm.

Traders of the [Main City](<Main City.md>)'s Bazaar become useful for the following reasons:
- Need gold fast? Sell some unique items with traders for gold
- Need one good more than another? Perform a trade
- Need an other-worldly item? Perform a trade or complete a Realm Request.
