## Overview
The Queen's Highway is the network of paths from each of the [Village](Village.md)s in the Realm. This network of highways are used to create [Route](Route.md)s for Shipments (see [Supply Chains](<Supply Chains.md>)).

Only coin from the [Queendom's Treasury](<Queendom's Treasury.md>) can be used to expand and upgrade this.
