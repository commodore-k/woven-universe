## Overview
The Queen's Highway is the network of paths from each of the [[Village]]s in the Realm. This network of highways are used to create [[Route]]s for Shipments (see [[Supply Chains]]).

Only coin from the [[Queendom's Treasury]] can be used to expand and upgrade this.
