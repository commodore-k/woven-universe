## Overview
This area resides inside the [[Queen's Manor]]

From here, the player can unlock counties if they've completed the [[Realm Quests]] to unlock that [[County]]. From there, they can [[Establish A Settlement]] for the Queen.


This is where players can manage the Realm's [[Supply Chains]].

This is all done through the [[World Map]].

## Locations

Logistic Halls can be found at the [[Queen's Manor]] as well as any [[Lord's Manor]] of a Village.
