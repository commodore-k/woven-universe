## Overview
Players play as Knights of the realm. Knights may also be referred to as a character the player plays as.

There is a fixed set of Knights available to players. Each one is a different type (think Path of Exiles II or Vampire Survivor).

A Knight will have a core gear set they are best with. However, a Knight can technically equip any base starting weapon from the Armory before they go to a Village.
