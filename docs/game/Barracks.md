## Overview
This is a building in the [[Main City]] that [[Player]]s spawn in when the game first boots up.

This is the building where players select which [[Knight]] they wish to play as. When the player first spawns from starting up the game, they will start as the last Knight they were when they left the game.

This is also where players can store their character's inventory into an inventory that any of their characters can access.
