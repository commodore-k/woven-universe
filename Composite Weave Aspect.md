The Allkin believe that the ability for Life in a Weave requires a specific set of [Weave Aspects](Weave%20Aspect.md) and in order to create those Weave Aspects, Weave Cords need to be bonded (i.e. combining Weave Cords tied to a specific Weave Aspect). And through these bondings of Weave Cords, they can create new and more complex ***Composite*** Weave Aspects. And they believe a set of Composite Weave Aspects could create beings like themselves.

The Allkin failed to create beings like themselves. However, with the 3 bondings, they *did* make a set of Composite Weave Aspects that did indeed create life, but one much weaker than themselves:

- Terrum Life Weave Aspect
- Terrum Death Weave Aspect
- Terrum Soul Weave Aspect
