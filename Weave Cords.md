Invented by [The All Mother](The%20All%20Mothers.md) [Stel](Stel.md), it is the product of [The Fifth Woven Axiom](The%20Fifth%20Woven%20Axiom.md). A Weave cord is a cording of Warp and Weft lines that make up a Weave. They can be created and bound to any being outside the Weave that the Weave Cord is made from and it allows that being to control a single Weave Aspect. For Example, Stel had multiple Weave Cords bound to her, some controlled gravity, others light.

You could think of a Weave Cord as a single string on a puppet. But to create a Weave Cord requires the Weave to be "lifted". Lorekeepers aren't quite sure what [Cerus](Cerus.md) meant by this, but in any case, when a weave is held up, one can create a Weave Cord.
