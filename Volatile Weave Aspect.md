## Overview
This [Weave Aspect](Weave%20Aspect.md) was woven into the [Terrum Weave](Terrum.md) during its [creation](The%20Woven%20Story.md#The%20Weaving%20of%20[Terrum](Terrum.md)) by the [Allkin](Allkin.md).

The Allkin [Arda](Arda.md) later bonded herself to this Weave Aspect with a [Weave Cord](Weave%20Cords.md).

## Aspect

Imbues the ability for existing matter definitions to have chemical reactions with one another in a Weave this Aspect is apart of. Useless if the [Material Weave Aspect](Material%20Weave%20Aspect.md) is not present in the same Weave as this Aspect. Also applies to states of matter if the [Fluidic Weave Aspect](Fluidic%20Weave%20Aspect.md) is present.

## Allkin Weave Cord Use

- Can create/update/destroy chemical reaction definitions for the existing matters (states of matter)
- Can generate the reaction of any existing chemical reaction between to existing matter definitions in the Terrum Weave without the required matter
- Can apply any reaction to an existing matter in any state in the Terrum Weave

## Terrum [Majik](Majik.md) Use

- Can generate the reaction of any existing chemical reaction between to existing matter definitions in the Terrum Weave without the required matter
- Can apply any reaction to an existing matter in any state in the Terrum Weave
