## Overview

This [Weave Aspect](Weave%20Aspect.md) was woven into the [Terrum Weave](Terrum.md) during its [creation](The%20Woven%20Story.md#The%20Weaving%20of%20[Terrum](Terrum.md)) by the [Allkin](Allkin.md).

[The All Mother](The%20All%20Mothers.md) - [Stel](Stel.md) later bonded herself to this Weave Aspect with a [Weave Cord](Weave%20Cords.md).

## Aspect

Imbues the ability to define natural constants and structure/order to the Aspects that exist in the Weave this Aspect is apart of.

## Allkin Weave Cord Use

- Can create/update/destroy universal constants in the Terrum Weave that other Aspects can leverage
- Can temporarily mutate the existing defined universal constants for as long as the Cord is being used for said mutation.
- Can be used to imbue a rune with a set of rules that can trigger the majik of any Weave Aspect the rune maker also has access to.

## Terrum [Majik](Majik.md) Use

- Can temporarily mutate the existing defined universal constants for as long it is being pulled on with blood.
- Can be used to imbue a rune with a set of rules that can trigger the majik of any Weave Aspect the rune maker also has access to.
	- For Maji of the [Cerelic Order](Cerelic%20Order.md) they can create runes that are imbued with majik from any of the following Weave Aspects
		- [Kinematic Weave Aspect](Kinematic%20Weave%20Aspect.md)
		- [Temporal Weave Aspect](Temporal%20Weave%20Aspect.md)
		- [Gravitic Weave Aspect](Gravitic%20Weave%20Aspect.md)
		- [Luminal Weave Aspect](Luminal%20Weave%20Aspect.md)
		- [Ordinal Weave Aspect](Ordinal%20Weave%20Aspect.md)
